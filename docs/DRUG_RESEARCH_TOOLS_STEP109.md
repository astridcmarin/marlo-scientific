# Step 109 — discoverable drug-specific research tools

The Drug and Model Library and Simulation Lab now share a source-checked registry for five bortezomib tools: the target-activity equation, time-course candidate, assumption experiment, peak-evidence review, and provisional figure review. New library filters select the three calculation categories independently.

Availability means the required pinned reference files can be verified. It does not mean the solver has run, the source model is reproduced, or a patient profile is applicable. Scientific status remains review_required for every bortezomib tool. Missing/altered inputs suppress dependent launch links without removing unrelated drug knowledge or lenalidomide tools.

Research tool counts are separate from the existing exposure, efficacy and toxicity model counts. Efficacy and toxicity model coverage remains zero. The time-course candidate does not become a patient exposure model. Evidence reviews do not become models.

No network requests, patient-record access, calculation, or database writes occur when browsing the registry. Tools retain their own runtime integrity checks. This step modifies no model equations, parameters, or scientific findings. JSON export retains source hashes, tool scope, outstanding issues, and selection separately from the full inventory.

Integrated directly into the repository after Step 108; no package installer or database migration is required. The main remaining scientific dependency is resolving the bortezomib elimination formulation against adequate source material, while other platform work may proceed independently.
