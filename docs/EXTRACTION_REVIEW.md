# Owner review of AI-assisted extractions

Written 31 October 2026.

## Why

Every extract on the platform is labelled "AI-assisted, independent review pending". The platform's main claim is that every number traces back to a source, and that claim currently rests on unreviewed extractions. This workflow lets the platform owner check the values that matter against the original documents and records the result, so the label can change.

## What is reviewed

`intelligence_store/data/extraction_review_queue_v1.json` (pinned in `extraction_review.py`) lists **166 values**: every value that feeds a calculation or a quoted dose. The file is generated by `scripts/build_extraction_review_queue.py` from the pinned extracts.

**Priority 1:**
- Hughes 2019 parameters and variability;
- Kim 2026 parameters;
- the CC-5013-PK-001 renal groups (the 25 mg reference and the outside checks);
- the lenalidomide exposure–safety odds ratios;
- the REVLIMID label doses and Table 3;
- the ixazomib Gupta 2017 parameters;
- the pomalidomide and dexamethasone label values.

**Priority 2:** the daratumumab Luo 2021 parameters (outside checks only; not run on any page).

**Not listed:** values the platform derives itself, such as the average daily dose of an every-other-day regimen, and uncertainty statistics such as RSEs and bootstrap intervals.

Each item gives the value, the file and JSON pointer, the location in the source, and where to look. The page refuses to load if any listed file has changed or any value no longer matches.

## How

1. Open `/models/extraction-review` (linked from `/models`).
2. For each value choose **Matches**, **Wrong** (with a note on what the source shows) or **Can't check**. The draft is kept in the browser.
3. Download the review record and run `flask extraction-review-check FILE`. This validates the record against the queue and prints its checksum.
4. Pin the record: add it to `intelligence_store/data/` and to `REVIEW_RECORDS` in `extraction_review.py` with its checksum. The page then shows each value's status.

A value found wrong is corrected by a new version of its extract, with a new pin and new checks where it feeds a result. It is never edited in place.

## What it does not do

- A review by the platform owner is not independent of the platform. Records name the reviewer, and pages will say "reviewed by the platform owner", not "independently verified".
- The review checks transcription only: whether the value is what the source says. It does not check whether the source is right or whether the model is applicable.
