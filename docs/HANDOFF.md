## Rules that are easy to break

- **The 200-trial eligibility v2 annotation and the v2 sample are the blind test data.** Never open, print or summarise their contents, and never run an extractor on them, except through the locked steps below. Sizes, dates, checksums and counts only. Tell every subagent, in its brief, not to open `instance/`, the annotation files or the v2 sample.
- **Locked checks keep two commits, plan then result.** Never squash them; PRs are merged with "Create a merge commit".
- **Pinned data never changes in place.** A new versioned file and a new SHA-256 pin; run `python3 scripts/data_file_index.py` after adding one.
- **One commit per update, about five updates per batch branch, one push and one PR per batch.** No `Co-Authored-By` trailers, session links or "Generated with" footers in commits or PR descriptions (`CLAUDE.md` overrides any tool default).
- **Synthetic inputs only; validation flags stay false.**
- **AI reviews are recorded in `docs/reviews/`** with the review as received and a Handling section that says what was checked against the code or PDFs and what was done. They are AI re-checks, never "reviews" in the evidence-state sense.

### 3. Acceptance rule v2 for more drugs (F03 follow-up)

The extended acceptance rule is now locked and committed, with the %RSE conversions documented as stated assumptions, three correlation scenarios (independent, +0.5, −0.5), and a 1.5× sensitivity run. The completed real-data run covers ixazomib (Gupta 2017): AUC across all six study groups and four kidney- and liver-impairment ratios to normal, across every scenario in the original check; and daratumumab (Luo 2021, both check versions): five first-dose endpoints in the main scenario only. Daratumumab was restricted to the main scenario because each virtual patient requires numerical simulation, making all eight scenarios computationally expensive; the original reports already document endpoint behavior across scenarios. Pomalidomide (Li 2017) was excluded because neither of its two checks compares simulated patients against observed data: one compares against label values within a tolerance band, and the other compares two models. Consequently, its parameter uncertainty is not an input to either check, and the 90% to 95% interval conversion is unnecessary. For uncertainty conversion, Gupta’s %RSE values are converted on the log scale, consistent with the paper’s table note, resulting in relatively small uncertainty (clearance approximately ±4%); Luo’s %RSE values are converted directly from the printed estimates. Clearance and volume are evaluated independently and under correlations of +0.5 and −0.5. A directional verdict is accepted only when all three scenarios agree; otherwise, it becomes indeterminate. The 1.5× %RSE sensitivity analysis is reported alongside the verdict without changing the acceptance decision. Before the uncertainty analysis, the new implementation reproduced the original check’s limits within simulation noise. Across 70 verdicts, 11 changed, and every change became indeterminate; none flipped direction from too low to too high or vice versa. For ixazomib, severe kidney impairment moved from too low to indeterminate because the observed AUC is within 1% of the widened limit. The liver-impairment finding remains too low in all three groups across every correlation scenario and the 1.5× sensitivity run, making it a robust finding. All four kidney- and liver-impairment ratios to normal remain consistent. For daratumumab, the 16 mg/kg first-week exposure finding moved from too high to indeterminate in both check versions because the observed value is within 5% of the limit. One correlation scenario retained the too-high verdict, but the acceptance rule requires agreement across all three. The other four endpoints remain consistent. The remaining nine changes occurred in ixazomib’s secondary scenarios, each moving from a directional verdict to indeterminate because it fell within 5% of the acceptance limit. Overall, incorporating published parameter uncertainty did not reverse any findings; it identified two previously directional findings as borderline relative to their acceptance limits. The 1.5× %RSE sensitivity run produced the same verdict classes, indicating that the results are not driven by the %RSE conversion. Gupta’s uncertainty remains small because its %RSE values are relative to log-scale estimates. Daratumumab was evaluated in its main analysis scenario only, as specified in the locked plan. The ledger, findings document (version 8), and per-drug status file are updated, and all tests pass.
